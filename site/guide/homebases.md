# Homebases and subjects

## Homebases

A **homebase** is a folder of notes: ordinary `.md` files and their attachments, which any other app can open. Keep
one for everything, or one per year or subject. Docketeer keeps its own settings for a homebase in a hidden `.quire`
folder inside it, so a homebase can be copied, backed up or synced (iCloud, Syncthing, a USB stick) as one folder.

A folder of Markdown notes you already have opens as a homebase as it is.

| | |
|---|---|
| **⌘⇧O**, or the homebase's name at the bottom left | Switch homebase: your recent ones, *Open a folder*, *Create a new homebase*, *Open the example homebase* |
| *Remove a homebase from this list* | Takes it off the list; the folder is not touched |

### Starting a new homebase

**Create a new homebase** asks which panels it should start with:

- **Legal**: Subjects, Authorities, Outline, Cite, Homebase and Layout, for law notes with AGLC4 citations.
- **Generic**: Files and Folders, Homebase and Layout. The others are hidden, not gone, and can be shown later.
- **Your own templates**: set up a homebase's panels the way you like them, then run **Save this homebase's panels as
  a template…**. Every new homebase can then start the same way, with the folders its panels show already made.

### The example homebase

**Try the example homebase** copies sample law notes into *Docketeer example* in your Documents: a topic summary, a
case brief, a lecture note with a recording and timestamps, a reading with page links and quotes, and an exam
checklist, in Torts and Contracts subjects. Change anything; opening it again opens your copy.

## Subjects and topics

The **Subjects** panel lists the folders you mark as **subjects** and **topics**, with their notes, so readings
folders, attachments and scratch notes stay out of the way. Mark a folder with **→** on it, here or in Homebase ›
Files. Marks follow a folder that is renamed or moved, and the folders themselves are not changed.

![The Subjects panel: the Torts subject, its Negligence topic and their notes](/screenshots/37-units-locked-note.png){.shot}

In the panel:

| Keys | |
|---|---|
| **N** / **T** | New note / new topic in the selected subject |
| **F2** | Rename |
| **Delete** (⌘⌫ on a Mac) | Delete (asks first, and says how many notes a folder holds) |
| **→** | Pin, move, archive, lock and the rest |

Your pinned and recent notes are at the top. The header of each note shows its subject › topic; clicking it opens
Subjects there.

## Homebase › Files

The **Homebase** panel shows every file and folder as a tree, with an icon for each kind (note, PDF, recording,
picture). **N** and **F** make a note or folder where you are; drag a file or folder onto another folder to move it,
and every link to it is updated.
