# Keyboard shortcuts

**⌘** is Command on a Mac and **Ctrl** on Linux, except in the Docket's key, **⌘D**, which is **Super+D** on Linux.
**⌥** is Option on a Mac and **Alt** on Linux. Every shortcut can be changed in **Settings → Hotkeys**, and the
Docket always lists the current ones: type `?` in it.

## The Docket

| Keys | |
|---|---|
| **⌘D** | Open or close the Docket |
| **⌘⇧D** | Peek or pinned |
| **⌘1** … **⌘9** | Show a panel |
| **⌘⌥↓ / ↑** | Taller / shorter |
| **↑ ↓** | Move through results and rows |
| **← →** (nothing typed) | Previous / next panel |
| **Enter** / **⌘Enter** / **⌥Enter** | Open here / to the right / below |
| **Shift+Enter** | Insert as a link |
| **→** or **⌘.** | Actions |
| **Tab / Shift+Tab** | Search box, results or panel, panel tabs |
| **Esc** | Back one step, or close |

Prefixes: `>` commands · `+` new note · `#` folders and tags · `/` headings in this note · `@` authorities ·
`~` outlines · `?` shortcuts

## Notes

| Keys | |
|---|---|
| **⌘N** | New note |
| **⌘;** | Add a property |
| **⌘⌥F** (Super+Alt+F on Linux) | Insert an AGLC4 footnote |
| **/** | The insert menu (at the start of a line or after a space) |
| **⌘⇧O** | Switch homebase |
| **⌘L** | Lock now |

## Panes

| Keys | |
|---|---|
| **⌘\\** / **⌘⇧\\** | Split right / down |
| **⌘⌥ arrows** | Go to the pane that way |
| **⌘⌥⇧ arrows** | Move the tab that way |
| **⌘⌃ arrows** (Mac) · **Ctrl+Alt+[ ] = -** (Linux) | Resize the pane |
| **⌘⇧=** | Even the panes out |
| **⌘⇧Enter** | Zoom the pane |
| **⌘W** / **⌘⇧T** | Close the tab / reopen it |
| **Ctrl+Tab** / **Ctrl+Shift+Tab** | Next / previous tab |

## Recordings and PDFs

| Keys | |
|---|---|
| **⌥T** | Insert a timestamp link |
| **⌥K** | Play or pause |
| **⌥J** / **⌥L** | Back / forward 5 seconds |
| **⌥,** / **⌥.** | Slower / faster |
| **⌥Q** | Quote the selected PDF text, with its page |

## Subjects and files

| Keys | |
|---|---|
| **N** / **T** | New note / new topic (Subjects) |
| **N** / **F** | New note / new folder (Homebase › Files) |
| **F2** | Rename |
| **Delete** (⌘⌫ on a Mac) | Delete |

## Studying

| Keys | |
|---|---|
| **Space** | Show the answer |
| **1** **2** **3** **4** | Again, Hard, Good, Easy (Space is Good) |
| **Space** in the Tasks panel | Check a task off |
